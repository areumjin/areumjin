## Selected Projects

### 01 / ReDo

**A mobile web app that helps designers put saved references to work.**

ReDo connects collecting inspiration with taking action. It helps users revisit why they saved a reference and apply it to a project.

- **Problem addressed** — The gap between saving references and using them in real work.
- **Features** — Save URLs with context and project tags; browse a context-based home feed; track actions and notes; explore AI-powered recommendations; install as a PWA; persist data with Supabase.
- **Stack** — React · TypeScript · Vite · Tailwind CSS · Supabase · Vercel.

[Explore the code →](https://github.com/areumjin/ReDo)

### 02 / Rolling

**A shared message board for friends and teammates.**

A team project that brings the tradition of passing around a paper filled with personal messages to the web.

- **Problem addressed** — Bringing messages and reactions together in one online space.
- **Features** — Create, edit, and delete rolling papers; react with emoji; interact through modals and toast notifications.

- **Stack** — React · JavaScript · HTML · CSS.
