## Selected Projects

### 01 / ReDo

**저장한 레퍼런스를 실제 작업에 활용하는 디자이너용 모바일 웹 앱**

레퍼런스를 모으는 데서 끝나지 않고, 저장한 이유를 다시 살펴보고 작업에 적용하도록 돕는 서비스입니다.

- **해결하려는 문제** — 저장한 레퍼런스와 실제 작업 사이의 연결.
- **주요 구현** — URL·저장 이유·프로젝트 태그 기반 저장, Context Box 홈 피드, 실행 메모, AI 기반 추천, PWA, Supabase 연동.
- **기술** — React · TypeScript · Vite · Tailwind CSS · Supabase · Vercel.

[프로젝트 코드 →](https://github.com/areumjin/ReDo)

### 02 / Rolling

**친구와 동료에게 마음을 전하는 웹 롤링페이퍼**

종이로 주고받던 롤링페이퍼를 웹으로 옮긴 팀 프로젝트입니다.

- **해결하려는 문제** — 온라인에서 메시지를 모으고 서로 반응을 나누는 경험.
- **주요 기능** — 롤링페이퍼 생성·수정·삭제, 이모지 반응, 모달과 토스트 UI.
- **참여** — 팀원으로 참여. 세부 담당 기능은 확인 후 추가 예정.
- **기술** — React · JavaScript · HTML · CSS.

[프로젝트 코드 →](https://github.com/areumjin/Rolling)

### 03 / Linkbrary

**링크를 카드로 정리하고 공유하는 웹 애플리케이션**
